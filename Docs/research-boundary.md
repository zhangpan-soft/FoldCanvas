# Research boundary

FoldCanvas is an engineering project exploring whether a 2D-authored, operation-based representation can make useful game-asset creation more accessible to humans and AI systems.

## Established engineering facts

- A 2D parameter domain can carry appearance coordinates for a generated surface.
- Deterministic operations can map sampled 2D panels into 3D.
- Explicit boundary and seam data can encode topology.
- Generated normals, thickness, and mesh topology can be compiler outputs.
- Domain-specific systems such as garments, sheet metal, and packaging already demonstrate that 2D source structure can compile or simulate into 3D outcomes.

## Hypotheses to test

- A small, composable operation language can cover a commercially useful fraction of game assets.
- AI systems will generate FoldScript more reliably than production-quality arbitrary meshes.
- Compiler diagnostics can support iterative AI repair.
- Non-modelers can author useful assets through 2D regions, seams, and operations.
- The source representation can remain simpler and more editable than generated mesh data.

## Claims the project does not make

- Every surface admits a distortion-free planar development.
- One finite operation set already covers every possible object.
- Surface encoding alone captures all volumetric internal structure.
- Black-hole holography is a proof of this engineering representation.
- AI can replace geometry validation.

Credibility is a feature. Public documentation must separate measured results, mathematical definitions, and speculative direction.
