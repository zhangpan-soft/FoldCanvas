# Goal

Deliver M17 on `agent/m17-stable-ga`: turn the exact M16 `ready` evidence into
an audited, deterministic, publicly qualified FoldCanvas `1.0.0` release while
preserving RC2 geometry and source semantics.

# User-visible proof

A user downloads `com.foldcanvas.core-1.0.0.tgz` from a non-prerelease GitHub
release, verifies its checksum, installs it into Unity `6000.3.20f1`, and
recompiles the maintained cup, sphere, and torus sources. Two clean hosted
consumers and an RC2-to-stable source-first upgrade produce matching evidence.

# Scope

# Test matrix

## Readiness

- exact downloaded report is ready and digest-bound
- wrong run/artifact/report/candidate/target/status/count/hash fails
- blocked or locally synthesized evidence cannot authorize publication

## Package and compatibility

- package, compiler, changelog, tag, contract, API baseline, and corpus baseline
  all report `1.0.0`
- normalized public API digest equals RC2
- ordered production-corpus cases and all per-case evidence equal RC2
- FoldScript fixture hashes and canonical output remain unchanged

## Release and public distribution

- repeated builds produce byte-identical archive/manifest/evidence
- stable GitHub metadata must be published, non-draft, and non-prerelease
- immutable RC2 prerelease verification fixtures still pass
- missing/extra/different assets, digests, tar metadata, stable evidence, or
  contract identity fail
- two public clean consumers and RC2-to-stable source upgrade produce real XML,
  Editor.log, and matching source/geometry evidence

# Risks and rollback

- **False stable promotion:** bind the exact ready run/artifact/report and
  re-query GitHub metadata in the tag workflow before release creation.
- **Version bump hides API change:** compare compiled signatures after
  normalizing only the reviewed version literal; any other delta fails.
- **Corpus drift:** compare complete ordered per-case evidence; version headers
  are the only permitted baseline change.
- **Prerelease/stable confusion:** derive expected GitHub metadata state from
  one selected contract and reject ambiguous tags.
- **Public package failure:** do not modify RC2; rollback remains its immutable
  archive and authoritative source.
- **User scratch contamination:** stage explicit files only and never include
  untracked `Project~` or `.meta` scratch files.

# Decisions made

- Stable `1.0.0` is a new deterministic package, not a relabeled RC2 asset.
- The version constant and version-bearing optional defaults may change from
  RC2 to stable; normalized public API type/member shape may not.
- The stable public upgrade baseline is RC2, using only canonical FoldScript
  and exact PNG source. Generated Mesh/OBJ/Material/Prefab/report state is not
  carried forward.
- Historical M14/M15 contracts remain immutable and are validated separately
  from the current stable contract.
- Stable GitHub publication is within delegated repository maintenance;
  external marketplace publication remains out of scope.
